Fractal SafeView

Desktop Software · Media Security · MIT License

“Don’t trust the file. Process it first.”

Fractal SafeView is a security-focused desktop video player that processes potentially untrusted MP4 files through full video and audio re-encoding before playback. By generating a fresh video instead of directly playing the original file, SafeView introduces an additional layer of protection between untrusted media and the playback environment.

How SafeView thinks about risk

Re-encoding is risk reduction, not a guarantee. Generating a fresh video meaningfully reduces exposure to malformed media, but it does not make a file provably safe — SafeView makes no such claim. Treat it as one additional layer of defense alongside careful file handling, never as the only one.

What it does

  • Full video and audio re-encoding into a fresh MP4 before anything is played
  • Progressive playback — playback can start once roughly 1 MB of the re-encoded file is ready
  • Seeking while the encoding is still running
  • Playback speed control from 0.5x to 2x
  • Frame-by-frame stepping
  • Fullscreen and Picture-in-Picture modes
  • Screenshot capture
  • Volume control and mute
  • Playback position memory between sessions
  • Drag-and-drop opening, native file picker, Windows “Open with” and command-line opening
  • Keyboard shortcuts for the whole player

Under the hood

  • Strict Electron main / preload / renderer process separation
  • Local streaming over localhost via MediaSource Extensions (MSE)
  • 10-minute transcode timeout for oversized or pathological files
  • Temporary processing directory for intermediate files

FractalLauncher

Desktop Software · Minecraft Launcher

FractalLauncher is a desktop Minecraft launcher built with Python, PyWebView and skinview3d. Its development covers the full launch pipeline: account management with Microsoft authentication, version management, game configuration with RAM and JVM argument controls, mod-loader support, skin and cape management, console-based diagnostics and theme customization.

FractalLauncher is an actively developed project — the feature set keeps evolving. The launcher’s own site is the single source of truth for its current status.

FractalScript

Programming Language · Software Development

FractalScript is a programming language project that evolved from EzCode. It is built around a custom execution environment and a register-based virtual machine prototype — an ongoing exploration of how language runtimes work beneath the surface.

FractalScript is an exploration project. Its design is developed step by step; the project site documents the current state of the language and its runtime.

About

About FractalLabs

FractalLabs represents the independent development work of a developer interested in software engineering, desktop applications, game development and emerging technologies. The focus is on building functional products, experimenting with unconventional ideas and understanding how things work beneath the surface. Rather than limiting development to one technology or discipline, projects are approached according to the problems they aim to solve.

There is no team page, no client list and no company history here — FractalLabs is exactly what the name suggests: independent development, carried end to end, from the first experiment to a working product. What ties the work together is shared engineering judgment rather than a shared product category.

Development philosophy

  • Functionality before decoration

    Everything starts with the question: does it work? Polish follows only after behavior is correct.

  • Practical engineering

    Solutions are chosen for the problem at hand, not for the résumé. The right tool is the one that ships.

  • Experimentation and iteration

    Prototypes are welcome and dead ends are expected — each attempt teaches something the next one uses.

  • Simplicity over unnecessary complexity

    The simplest design that satisfies the requirements wins, even when a more elaborate one would look better.

  • Building real, usable software

    The goal is software meant to be used daily, not demos that exist only to be shown once.

The Fractal ecosystem

Fractal is the shared name under which FractalLabs software ships. Each project carries it — Fractal SafeView, FractalLauncher, FractalScript — and follows the same rule: understand every layer of the stack you depend on.
